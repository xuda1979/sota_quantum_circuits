# Replication Report

**Paper:** *Discovering state-of-the-art quantum circuits with large language models*
Andi Gu, Alek H. Kemeny, Susanne F. Yelin, Mikhail D. Lukin (Harvard / Anthropic)
arXiv:2610.22367 [quant-ph], 15 Oct 2026 (v1); 46 pages, 10 figures, 6 tables.

**Replication date:** 2026-11-13
**Official code:** https://github.com/andigu/uncompute (cloned at `./uncompute`, Apache-2.0)

## What was replicated

The paper introduces an evolutionary framework in which an LLM proposes quantum circuit
designs (as Python programs) and an independent **evaluator** verifies and scores them
in the *kickmix* circuit model (classical reversible gates + measurement-based
uncomputation + diagonal phase gates). Candidates are ranked by **TQ-cost** =
(executed Toffoli count T) x (peak live qubit count Q).

The replication here covers:

1. **All 8 discovered circuits** of Table I, rebuilt from source (`circuit.py`) and
   re-verified end-to-end by the evaluator (correctness on randomized shots drawn from
   each task's distribution + exact cost accounting).
2. **All published baselines** in the repository, rebuilt and re-verified the same way.
3. **The complete divstep Toffoli-qubit trade-off family** (j_store = 5..9, fill, wide)
   and the second discovered Euclidean circuit of SI II.2.

## Environment

- Python 3.12.16 (uv venv), dependencies per `pyproject.toml` (numpy, galois, mpmath, click, ...)
- Evaluator: official C kernel (`uncompute/evalcore/_kernel.c`, built with gcc-15 -O3
  -march=native), loaded by the pure-Python reference loader.
  (`UNCOMPUTE_KERNEL` executor reported: `kernel`.)
- 12-core host, 22 GiB RAM. No results depend on parallelism (tooling states results
  are shard/join invariant).

## Method

Each circuit entry was evaluated with the official tooling:

```
python tools/eval.py <task> [--circuit <path>]
```

This runs the circuit's Python builder as a subprocess, streams the emitted op stream
through a FIFO, hashes it (the hash seeds the test draw), then executes every test
shot in the kickmix simulator, checking:

- output registers match the task reference function,
- the global sign equals the expected sign,
- every ancilla qubit returns to |0> (no dirty qubits),
- failure counts stay within each grader's budget (e.g. 100/100,000 for DQI decoders,
  20/100,000 for modinv point addition).

Costs (executed Toffoli count, peak live qubits, TQ-cost) are measured from the emitted
op stream exactly, not estimated.

## Reproduction notes

- The evaluator draws test inputs deterministically from SHA256 of the emitted op
  stream, so a byte-identical rebuild yields the identical test suite. All rebuilds
  produced byte-identical op streams (verified by comparing this run's measured T/Q/TQ
  and failure counts to the certified rows; `h_ops` hashes also matched where checked).
- The optional C kernel is a speed optimization only; the pure-Python reference
  evaluator is normative (README). Only the C kernel was used here.
- chemistry-fe2s2 runs 18,419,296 shots (1,642,080 structured probes + 2^24 random);
  both its circuits passed with zero wrong-output/wrong-sign shots.
- dqi-hermitian's sakata-fengrao baseline is the largest circuit evaluated
  (104,263,342 Toffolis, 194,053 qubits, TQ ~ 2.0x10^13); it passed 100,000 shots
  with 0 failures in ~21 min wall time using the C kernel.

## Optimality certificate for the paper's F24 showcase (new, 2026-11-17)

Beyond exact replication, the harness adds what the paper does not have:
a machine-checkable optimality certificate for the paper's own toy
demonstration (F24 inversion, Extended Data Fig. 1; the paper's discovered
circuit has T = 5, Q = 10, TQ = 50).

**Certificate legs (each regenerable; `run_all.sh`, module
`sota_harness/sota_harness/certificates.py`):**

| Leg | Statement | Model | Evidence |
|---|---|---|---|
| T >= 5 (any Q) | No 4-Toffoli circuit exists at ANY qubit count | kickmix model, ancillas unrestricted, h-bits allowed as operand sources, zero phase | rank proof: rank span{d2(INV_b)} = 4; complete 171-product first-op menu has 31 products with d2 = 0 and 140 with d2 outside W = span{d2(INV_b)}, none nonzero inside; a 4-product spanning set of the 4-dim W must lie inside W - contradiction. Cross-checked by exhaustive 2-ancilla DFS (tsearch, 343 nodes, 0.01 s) |
| Q >= 9 at any T (strict model) | No 0-ancilla circuit with x-wire-only operands at ANY Toffoli count | operands = transiently shaped x-wires; h-bits are pure targets | the four targets' d2 vectors lie outside the 6-dimensional span of the 35 realizable x-pair product d2s (full space dim 11); `q8probe.py` |
| Q >= 10 at T=5 | No 1-ancilla, 5-Toffoli circuit in the paper's operand idiom | one ancilla t; t-ops = x-affine operand pairs (MBU-freeable); h-ops = x-affine or (t-prefix & x-affine) pairs; free snapshots cx(t,h[b]); free final affine assembly | exhaustive deterministic DFS: NOT FOUND after exactly 6,725,331 nodes (reproduced twice, identical count); `q9search.py 5` |
| existence | A T=5, Q=10 circuit exists | - | the paper's circuit (Ext. Data Fig. 1c), (T, Q) as published; our own independent physical-wire synthesis attempt (`physsearch.py`) timed out inconclusively at 13.3M+ nodes (`results/physsearch.txt`); an exhaustive two-ancilla search in the widened h-source model (`existsearch.py`) closed NOT FOUND after 74,594,457 nodes — no circuit in that model, so no beating candidate passed the emit + evaluator gate (`results/existsearch_v3.txt`) |

**Strengthening beyond the initially-searched models (2026-11-17):**

- The T >= 5 leg was upgraded from "2 ancillas" to "any Q" via the rank
  argument above; it also covers h-bits as operand sources (their products'
  x-parts are old-menu products or 0, and their h-cross content cannot lie
  in the x-only target span).
- Tower-field / Frobenius attack: free squarings/basis changes do not
  enlarge the product menu (products of affine forms are closed under
  linear composition), and the best tower chain for x^-1 = x^14 needs
  2 F16 multiplications = 8 Toffolis > 5. Negative result.
- Widened h-as-source searches: Q=8 (`q8hsrc.py`) and Q=9 (`q9hsrc.py`)
  did NOT close within their compute budgets, honestly recorded as
  TIMEOUT/inconclusive (not NOT-FOUND proofs): Q=8 reached 13,300,000
  DFS nodes in 7,225 s; Q=9 reached 24,200,000 DFS nodes in 14,407 s
  (4 h deadline). No beating circuit was found in either explored
  space — consistent with, but not a proof of, the certificate
  (`results/q8hsrc.txt`, `results/q9hsrc.txt`).
- The finalized sound two-ancilla (Q=10) h-source model (`existsearch.py`,
  revised v3: ancilla-targeted ops = MBU-safe x-affine pairs only,
  h-targeted ops = x/t/u/tu/h-source families, t/u truth-table state,
  basis-inclusive memo) **did close exhaustively**: NOT FOUND after
  74,594,457 nodes (1,644.1 s, 18,225 memo states). This is a scoped
  exhaustive negative at T=5, Q=10 in the widest sound subclass
  searched. The model is a strict subclass of Q=10 circuits: the
  paper's own (T=5, Q=10) circuit exists, so it necessarily uses
  operations outside this subclass; the closure therefore asserts no
  circuit in *this model*, not that no two-ancilla circuit exists —
  but it is strictly stronger than the two TIMEOUTs above. No circuit
  in that model, so no candidate existed to pass the emit +
  `f24_evaluator.py` gate; the existence leg remains on the paper's
  published circuit (`results/existsearch_v3.txt`).

**Corrected records:** two search scripts carried stale optimistic
docstrings from earlier sessions (`finalsearch.py` "TQ = 45 < 50!",
`tsrcsearch.py` "better than the paper's 50!") although their runs return
NOT FOUND; both were fixed to state the actual negative results. The
candidate circuit directory `framework_replication/candidates/` is empty;
no unverified circuit claims remain in the repository.



All 17 circuit entries of the official `andigu/uncompute` repository - the eight
LLM-discovered circuits of Table I, every included baseline, and the full divstep
Toffoli-qubit frontier - were rebuilt from source and re-verified end-to-end with the
paper's exact evaluator. Every executed Toffoli count, peak-qubit count, TQ-cost, and
statistical failure count matches the certified values and the paper's Table I
exactly. The replication confirms the paper's headline claims:

- 12x TQ-cost reduction for the Reed-Solomon DQI decoder (Berlekamp-Massey with
  conditional routing and decoded history),
- 32x for the HHL rotation angle (dyadic leaves + shared local coordinate + direct
  accumulation),
- 9.9x Coulomb, 39.1x Gaussian, 4.1x Fe2S2 chemistry, 7.7x lattice gauge,
- a first reversible prime-field divstep inversion (4.0M Toffolis x 935 qubits) with a
  tunable Toffoli-qubit frontier, and a 3.4x-Toffoli specialized Euclidean variant,
- 9,100x for the Hermitian decoder vs. its naive reversible Feng-Rao baseline.

**Certificate conclusion:** within the precisely-stated models above, the
paper's discovered (T=5, Q=10) F24 circuit is simultaneously T-optimal
(no 4-Toffoli circuit at any qubit count) and Q-optimal at T=5 (no
0-ancilla circuit at any T in the strict operand model; no 1-ancilla
circuit in the paper's own operand idiom, exhaustively: 6,725,331 nodes).
The paper itself proves no optimality anywhere; this certificate is, to
our knowledge, the first for any circuit in this setting. Worked example
of the harness's value proposition: deterministic, LLM-free provers
certifying LLM-discovered circuits.
